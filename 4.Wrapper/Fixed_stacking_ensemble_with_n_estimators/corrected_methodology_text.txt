To evaluate the model performance, a repeated cross-validation approach was used. Specifically, the RepeatedKFold cross-validation technique was applied, with 5 folds and 2 repetitions, resulting in a total of 10 different train-validation splits. In each fold of the cross-validation, the dataset was randomly shuffled and then split into a training set (approximately 109 samples) and a validation set (approximately 27 samples). This ensured that the validation data was randomly selected from the full dataset for each fold and repetition.

Then, for each fold, we trained a variety of base models (e.g., GBR, RF, Support Vector Regressor (SVR), Lasso, and ElasticNet algorithms). Each algorithm underwent hyperparameter optimization using GridSearchCV with 5-fold cross-validation on the training set and predefined parameter grids (see Table S2 in Supporting Information). Additionally, for the tree-based models (GBR and RF), the number of base estimators was also tuned, testing values starting from 1, 10, 50, 100, and then incrementing by 100 up to 1000, to determine the optimal number of estimators. Overall, taking into account both the individual algorithms and variations in base estimators, we assessed a total of 25 models.

To prevent overfitting of the meta-model, out-of-fold (OOF) predictions were generated for the training set. Specifically, after hyperparameter tuning, each optimized base model was applied using 5-fold cross-validation on the training set via the cross_val_predict function. This ensured that predictions for each training sample were made by a model that had not seen that sample during training. Subsequently, each base model was retrained on the full training set to generate predictions on the validation set. The best base models (according to the lowest MAE) were selected to create the ensemble.

These OOF predictions from the training set served as the meta-features for training the meta-model, while the validation set predictions were used for final performance evaluation. Therefore, the meta-feature matrix for training had rows corresponding to the number of training samples (approximately 109 per fold) and columns corresponding to the number of base models (i.e., 5). This nested cross-validation approach with OOF predictions ensures unbiased performance estimates and prevents data leakage between the base models and the meta-model.
