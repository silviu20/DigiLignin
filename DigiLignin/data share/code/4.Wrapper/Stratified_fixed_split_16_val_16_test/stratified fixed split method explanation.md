Stratified Fixed-Split Ensemble Learning Regression
To complement the repeated K-fold cross-validation approach and provide an alternative validation strategy, a stratified fixed-split ensemble method was implemented. This approach employed a single, fixed data partition with stratified sampling to ensure representative distribution across all data splits, particularly critical when working with limited validation and test set sizes. The dataset was divided into training (~100 samples), validation (16 samples), and test (16 samples) sets using systematic stratified sampling to maintain representative target variable distribution across all splits.

The fundamental distinction of this approach lies in its data splitting strategy. Rather than employing random or repeated cross-validation splits, a stratified splitting technique was implemented to ensure that the validation and test sets were representative of the entire target variable distribution. This was particularly important given the relatively small sizes of the validation and test sets (16 samples each). The stratified splitting process involved three sequential steps: (1) sorting all samples by the target variable (Tg) in ascending order, (2) applying systematic sampling to select 16 validation samples evenly distributed across the sorted target range, and (3) applying systematic sampling again to the remaining samples to select 16 test samples, with all remaining samples (~100) allocated to the training set. This systematic approach ensured that low, medium, and high Tg values were proportionally represented in all three data partitions, thereby preventing the bias that could arise from random sampling with small validation and test sets.

The distribution quality of the stratified split was verified by calculating and comparing statistical measures (mean, standard deviation, minimum, and maximum) of the target variable across the training, validation, and test sets. These statistics confirmed that all three sets maintained similar distributional characteristics, ensuring that model evaluation would be conducted on truly representative data. The fixed nature of this split—using a consistent random seed (42) across all experiments—guaranteed reproducibility and enabled fair comparison across different feature combinations and model configurations.

Furthermore, the model development process was structured to comprehensively explore the feature space and model complexity. A total of 63 feature combinations were systematically evaluated, derived from three mandatory features (Lignin (wt%), Co-polyol type (PTHF), and r) combined with all possible subsets of six optional features (Copolyol (wt%), Isocyanate (wt%), Isocyanate (mmol NCO), Isocyonate type, tin(II) octoate, and Sratio(%)). This combinatorial approach ranged from feature sets containing 4 features to those containing all 9 features, enabling identification of the optimal feature subset for Tg prediction.

For each feature combination, the ensemble learning process proceeded in two distinct layers. The first layer consisted of five diverse base models: Gradient Boosting Regressor (GBR), Random Forest Regressor (RF), Support Vector Regressor (SVR), Lasso regression, and ElasticNet regression. Each base model underwent hyperparameter optimization using GridSearchCV with predefined parameter grids. For GBR, the hyperparameter grid included learning rates of [0.01, 0.1, 0.2] and maximum depths of [3, 5, 7]. For RF, the grid encompassed maximum depths of [None, 10, 20] and minimum samples split of [2, 5, 10]. SVR was tuned across C values of [0.1, 1, 10], kernels of [rbf, linear], and gamma values of [scale, auto]. Lasso and ElasticNet were optimized over alpha values of [0.1, 1, 10], with ElasticNet additionally exploring l1_ratio values of [0.1, 0.5, 0.9]. Additionally, for the tree-based models (GBR and RF), the number of base estimators was systematically varied, testing values of 1, 10, 50, 100, 200, 300, 400, 500, 600, 700, 800, 900, and 1000 to determine the optimal ensemble complexity.

A critical aspect of the base model training was the hyperparameter tuning strategy. To leverage the fixed validation set for hyperparameter selection while maintaining proper data separation, the training and validation sets were temporarily combined for GridSearchCV, with a custom cross-validation split that designated the training samples as the training fold and the validation samples as the validation fold. This ensured that hyperparameter selection was based on performance on the fixed validation set. After identifying the optimal hyperparameters, each base model was retrained exclusively on the training set to prevent data leakage. The trained base models then generated predictions on all three data partitions (training, validation, and test sets), creating the meta-features for the second layer of the ensemble.

Prior to model training, all features and the target variable were scaled using RobustScaler, which employs the median and interquartile range rather than mean and standard deviation. This scaling approach was chosen for its robustness to outliers. Critically, the scaler was fitted exclusively on the training set and then applied to transform the validation and test sets, maintaining strict data separation to prevent information leakage.

The second layer of the ensemble consisted of a meta-model implemented using Ridge regression. The meta-model received as input a meta-feature matrix with dimensions corresponding to the number of samples (rows) and the number of base models (columns, i.e., 5). For the training set, this resulted in a matrix of approximately [100 × 5], while the validation and test sets each produced [16 × 5] meta-feature matrices. The Ridge regression meta-model learned optimal weights for combining the predictions from the five diverse base models, effectively capturing complementary strengths and mitigating individual model weaknesses. Unlike the base models, the meta-model did not undergo hyperparameter tuning; instead, it was trained with default Ridge regression parameters on the training set meta-features and evaluated on the validation and test set meta-features.

Model performance was assessed using three complementary metrics: coefficient of determination (R²), mean squared error (MSE), and mean absolute error (MAE). Importantly, all metrics were calculated on the original scale of the target variable (°C) by applying inverse transformation using the fitted y-scaler, ensuring interpretability of the results. Metrics were computed separately for the training, validation, and test sets, providing comprehensive insight into model fitting, hyperparameter selection quality, and generalization performance, respectively.

The comprehensive experimental design resulted in 819 total experiments (63 feature combinations × 13 n_estimators values), with each experiment training 6 models (5 base models + 1 meta-model), yielding approximately 4,914 trained models. To manage this computational complexity and ensure robustness against interruptions, a checkpoint system was implemented that saved results incrementally after each feature combination was completed. This system tracked completed (feature combination, n_estimators) pairs and enabled seamless resumption from the point of interruption if needed.

All results were systematically recorded in two primary outputs: a results file containing performance metrics (R², MSE, MAE) for all experiments across training, validation, and test sets, and a model registry file documenting detailed metadata for each trained model, including hyperparameters, feature combinations, and performance metrics. Additionally, split statistics were saved to document the distributional characteristics of the training, validation, and test sets, ensuring transparency and reproducibility of the data partitioning strategy.

The final analysis identified the optimal feature combination and n_estimators value based on test set performance, specifically minimizing test MAE while monitoring validation MAE to assess consistency. This stratified fixed-split approach provided a rigorous, reproducible framework for model selection and performance estimation, complementing the repeated K-fold cross-validation methodology by offering an alternative perspective on model generalization through a single, carefully constructed holdout test set.
