# Graphical Abstract Text (Updated)

A stacking ensemble model combining five base learners accurately predicts the glass transition temperature of lignin-based polyurethanes within 6.66°C, trained on a dataset of only 136 experimental formulations. Seven key input features—including lignin content, co-polyol chain length, isocyanate type, [NCO]/[OH] ratio, and swelling ratio—drive predictions that outperform all individual base models. Systematic mapping of over 4 million novel formulation combinations reveals complex non-monotonic structure–property relationships, while an adaptive grid search algorithm enables target-Tg-driven optimisation. A parallel coordinates interface translates the model's outputs into actionable synthesis formulations, accelerating the adoption of sustainable lignin-based polyurethanes.
